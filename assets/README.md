# Asset organization

- `brand/` — portfolio logo, profile image, and social preview
- `backgrounds/` — shared page and card backgrounds
- `documents/` — downloadable documents such as the resume
- `media/` — shared video media
- `previews/` — full-page portfolio captures used for reference
- `projects/applications/` — application project screenshots and animations
- `projects/web/` — client and web-work screenshots and animations
- `projects/jerseystem/` — JerseySTEM case-study assets

Use lowercase kebab-case names for new project assets where practical. Keep each future case study in its own folder under `projects/`.
